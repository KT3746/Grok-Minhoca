# MINHOCA

Jogo de navegador estilo artilharia por turnos: dois pelotões, terra que some e explosões.

Não é Worms. É MINHOCA.

**Jogar:** [kt3746.github.io/Grok-Minhoca](https://kt3746.github.io/Grok-Minhoca/)

Feito com Grok Build.

## Como abrir

```bash
npm install
npm run dev
```

Abra o endereço que aparecer (em geral `http://localhost:8080`).

## Controles

- **A / D** ou setas: andar
- **W / S** ou setas: mirar
- **Espaço**: segure para carregar a potência, solte para atirar
- **J** ou **Shift**: pular
- **N**: passar a vez
- **1–6**: armas (bazuca, granada, dinamite, shotgun, soco, ataque aéreo)
- **Esc / P**: pausa

No celular, use o pad e o botão FOGO. Arraste no campo para mirar.

## Modos

- Contra a CPU (recruta, veterano ou maluco)
- Dois jogadores no mesmo aparelho

Mapas: colinas, cânion ou ilhas. O vento empurra foguetes e bombas.

## Dicas

Explosões cavam o chão. Queda, água e fogo amigo também matam. O último pelotão em pé vence.
